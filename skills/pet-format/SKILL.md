# Claude Pets format v3 (summary)

The normative contract is [pet-format-v3.md](../../docs/pet-format-v3.md). This is a quick reference; when a detail matters (frame counts, durations, arbiter rules), read the spec. The CLIs are in `${CLAUDE_PLUGIN_ROOT}/tools/`; to make a pet use the `hatch-pet` skill, to convert a Codex pet use `import-codex-pet`.

## Package layout

```text
~/.claude/pets/<pet-id>/
├── pet.json
├── spritesheet.png     # 8 x 22 atlas, source of truth
└── strips/<animation>.png   # one horizontal strip per drawn animation
```

`strips/` is generated by `package_pet.py` from the atlas; the mod reads only strips. A package without strips does not load. `<pet-id>` equals the `id` in `pet.json`.

## Atlas

- 8 columns x 22 rows. Cell `cell.width` x `cell.height`, each 16-128.
- Atlas = `8 * width` x `22 * height`, RGBA PNG, transparent background.
- A row's used cells are its leading `frames` cells; the rest are fully transparent. More than 8 frames continue on the next row. Custom animations extend the atlas downward by whole rows.
- Rows 9 and 10 hold the 16 `look` directions (clockwise from up: 000, 022.5, ... 337.5).

## Pixel-art rules (enforced by `validate_pet.py`)

1. Cell at most 128 x 128.
2. Binary alpha (0 or 255).
3. At most `pixelArt.maxColors` opaque colours per cell (default 64, hard limit 256).
4. Native pixel size, never pre-upscaled (no uniform n x n blocks).
5. Each strip PNG at most 96 KiB.

Fix guidance: `hatch-pet` references, `pixel-art-rules.md`.

## pet.json

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "One short sentence.",
  "author": "Name or handle",
  "license": "CC-BY-4.0",
  "spriteVersionNumber": 3,
  "spritesheetPath": "spritesheet.png",
  "stripsPath": "strips",
  "cell": { "width": 64, "height": 64 },
  "pixelArt": { "maxColors": 64 },
  "animations": {}
}
```

- `id`: lowercase letters, digits, hyphens; equals the folder name.
- `spriteVersionNumber` must be 3.
- `pixelArt`: `{ "maxColors": N }`. Only imported non-pixel Codex pets use `false` (rules become warnings).
- `animations`: optional per-animation overrides (see below). Unknown top-level fields are ignored.

## Animations

Each has `row`, `frames` (1-16), `durations` (ms per frame, or one value for all), `loop` (state vs one-shot), `priority` (P0-P6), `minMs` (default 600), `next` (one-shots only), `fallback`.

| Row | Name | Frames | Kind | Priority | Fallback |
| --- | --- | --: | --- | --- | --- |
| 0 | `idle` | 6 | loop | P6 | none (required) |
| 1 | `walk-right` | 8 | loop | P6 | `idle` |
| 2 | `walk-left` | 8 | loop | P6 | `idle` |
| 3 | `waving` | 4 | once | P5 | `idle` |
| 4 | `jumping` | 5 | once | P3 | `idle` |
| 5 | `failed` | 8 | once | P2 | `idle` |
| 6 | `waiting` | 6 | loop | P1 | `idle` |
| 7 | `working` | 6 | loop | P4 | `idle` |
| 8 | `review` | 6 | loop | P4 | `working` |
| 9-10 | `look` | 16 | pose | P6 | `idle` |
| 11 | `sleeping` | 6 | loop | P6 | `idle` |
| 12 | `waking` | 6 | once | P5 | `idle` |
| 13 | `summoning` | 6 | once | P4 | `waving` |
| 14 | `celebrating` | 8 | once | P3 | `jumping` |
| 15 | `confused` | 6 | once | P2 | `failed` |
| 16 | `eating` | 6 | loop | P4 | `working` |
| 17 | `fidget` | 6 | once | P6 | `idle` |

| 21 | `petted` | 6 | once | P0 | `waving` |

Durations are in the spec table. Rows 0-10 keep Codex v2's meaning and order.

## Custom animations

A key in `animations` that is not a standard name declares a custom animation. It must give `row` (22 or more, whole rows, no overlap with another animation), `frames`, `durations` and `fallback`. Default priority is P4. Pass `--pet-json pet.json` to `extract_strip_frames.py` and `compose_atlas.py` so they know the row.

```json
"animations": {
  "dance": { "row": 22, "frames": 8, "durations": [120], "loop": false, "priority": "P4", "fallback": "celebrating" }
}
```

Overrides for standard animations may set any field, for example `"idle": { "durations": [300] }`.

## Priorities and fallbacks

P0 user interaction, P1 needs the person, P2 bad outcome, P3 good outcome, P4 activity, P5 transition, P6 ambient. Loops are states, one-shots are reactions; the shown loop is the highest-priority loop across sources; a one-shot interrupts only a loop of equal or lower priority and is otherwise dropped; one-shots within 1500 ms coalesce; an animation stays at least `minMs`; `waking` plays first when something above P6 happens during `sleeping`; after `duck-in` the pet is hidden until `pop-out`.

If a pet's cells for an animation are all transparent (or a custom animation is missing), the `fallback` chain is followed until a drawn animation is reached. `idle` must always be drawn, so a minimal pet is just `idle`. Reduced motion shows each animation's first frame only.
